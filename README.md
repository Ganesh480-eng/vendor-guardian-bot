# VendorGuard AI

AI-powered vendor security risk assessment agent built for real-world compliance workflows. VendorGuard AI automates vendor evaluation by analyzing security posture, compliance evidence, risk indicators, and generating audit-ready decisions.

Built for:
**Hindsight Hackathon 2026 – Persistent Memory + AI Agents**

---

## Problem Statement

Organizations spend days or weeks manually reviewing vendors using questionnaires, spreadsheets, and fragmented evidence sources.

Problems:
- Procurement teams face lengthy security reviews
- Security teams repeat the same vendor assessments
- Compliance teams chase missing evidence
- Founders often bypass reviews (shadow IT risk)

VendorGuard AI solves this by delivering vendor risk assessments in seconds.

---

## Features

- Vendor risk scoring
- SOC2 / GDPR / ISO compliance checks
- AI-powered recommendations
- Audit trail generation
- ArmorIQ policy-gated approvals
- Persistent memory-based vendor recall
- Real-time evaluation workflow

---

## How It Works

Vendor Input  
↓  
Research & Data Collection  
↓  
Hindsight Memory Recall  
↓  
AI Risk Analysis  
↓  
ArmorIQ Policy Gate  
↓  
Audit Log + Final Decision
